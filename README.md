# 42 C++ Modules

This repository contains my work for the 42 School C++ curriculum.
The modules are designed to build strong foundations in modern C++ by progressing from core language features to object-oriented design and standard library usage.

## Curriculum Scope

The 42 C++ modules focus on:

- C++ syntax and compilation model
- Classes, objects, encapsulation, and canonical form
- Inheritance and polymorphism
- Abstract classes and interfaces
- Exceptions and error handling
- Templates and generic programming
- STL containers, iterators, and algorithms

## Repository Structure

Each module is organized in its own directory (for example `cpp_00`, `cpp_01`, etc.) and usually contains:

- Exercise folders or source files for each required task
- A `Makefile` to build the project
- Any module-specific helper files

## Build and Run

Most exercises follow the same workflow:

1. Enter a module directory.
2. Build with `make`.
3. Run the generated executable.

Example:

```bash
cd cpp_00
make
./megaphone
```

## Learning Goals

This repository is primarily intended to:

- Practice writing idiomatic, readable C++
- Reinforce OOP design principles through constrained exercises
- Develop confidence with memory management and resource ownership
- Gain practical fluency with the STL and generic code patterns

## Notes

- All projects are implemented according to 42 subject constraints.
- Some modules intentionally restrict parts of the standard library to emphasize core concepts.
- Code style and architecture may evolve from one module to the next as concepts become more advanced.
